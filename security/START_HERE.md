# 明日の作業メモ（倉治整骨院）

Cloudflareアカウントがなければ、作業の途中で作成が必要です。作成できない場合は公開GASへの切替を止め、予約とLINEを現状のまま維持します。

## 秘密情報の扱い

`LINE_TOKEN`、`LINE_CHANNEL_SECRET`、`LINE_WEBHOOK_FORWARD_KEY` の**値をチャット・GitHub・HTML・スクリーンショットへ載せない**でください。値は各サービスの設定画面で直接入力します。すでにテスト送信が成功した新しいLINEトークンは再発行不要です。

## 切替の停止条件

- 管理画面から予約が読めない／編集できない場合、公開GASは更新しません。
- LINEの友だちからの実際のメッセージが届かない場合、公開GASは更新しません。
- 患者さんのWeb予約フォームから送信できない場合、次の段階へ進みません。

細かなコピー対象ファイルとプロパティ名は [`README.md`](README.md) にあります。
